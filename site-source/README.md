# Source du site officiel Le Rempart

Le site publié est dans `../site/` (généré, ne pas modifier à la main).

- Textes et données : `contenu/site.json`, `contenu/gites.json`, `contenu/region.json`.
- Générer : `python3 build.py` (Pillow requis pour les images).
- Le site reste en `noindex` tant que `indexable` vaut `false` dans `site.json`.
- Les valeurs marquées « PROVISOIRE » sont à confirmer par le propriétaire.
